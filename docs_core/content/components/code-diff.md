# CodeDiff

코드 변경 사항을 라인 단위로 비교해서 보여주는 read-only viewer입니다. 추가된
라인은 success 톤으로, 삭제된 라인은 error 톤으로 강조하며 변경 없는 라인은
그대로 둡니다. PR 리뷰, 변경 이력 표시, 마이그레이션 가이드 등에 사용합니다.

> 이미지나 텍스트 두 가지를 좌우로 비교하는 split-view UI 가 필요하다면
> [`Diff`](/components/diff) 컴포넌트를 사용하세요.

## 사용 시기 (When to Use)

**이 컴포넌트를 사용하세요:**
- PR / 커밋 변경 사항을 라인 단위로 보여줄 때
- 마이그레이션 가이드에서 "이전 → 이후" 코드를 강조할 때
- 변경 이력(audit log)을 코드 형태로 보여줄 때

**대신 다른 컴포넌트를 사용하세요:**
- **[CodeSnippet](/components/code-snippet)**: 단일 코드 블록을 보여줄 때 (변경 표시 없음)
- **[Diff](/components/diff)**: 코드 행 데이터의 추가/삭제 대신 두 콘텐츠 층을 분할선으로 비교할 때

## 예제

```dart
CodeDiff(
  lines: [
    CoreCodeDiffLine(
      text: 'class MyWidget extends StatelessWidget {',
      type: CoreCodeDiffLineType.unchanged,
      lineNumber: 1,
    ),
    CoreCodeDiffLine(
      text: "  return Text('Hello');",
      type: CoreCodeDiffLineType.removed,
      lineNumber: 2,
    ),
    CoreCodeDiffLine(
      text: "  return Text('Hello').bodyMedium;",
      type: CoreCodeDiffLineType.added,
      lineNumber: 2,
    ),
  ],
)
```

## 동작 스펙 (Behavior)

- `lines` 를 받은 순서대로 렌더합니다. added는 `+ `, removed는 `- `, unchanged는 공백 prefix이며 두 파일의 diff를 자동 계산하지 않습니다.
- 줄 번호는 `showLineNumbers` 가 참이고 각 행의 `lineNumber` 가 있을 때만 표시합니다. 번호를 새로 생성하거나 재정렬하지 않습니다.
- `onLineTap` 이 있으면 행을 `Clickable` 로 감싸 탭 · Enter · Space에서 그 행을 전달하고, 없으면 표시 전용입니다. 선택·편집·비활성·복사 기능은 없습니다.

## 사용 가이드라인 (Usage Guidelines)

### ✅ Do

<Callout type="tip">

**추가/삭제가 있는 실제 변경 비교에만 사용**

```dart
CodeDiff(
  lines: [
    CoreCodeDiffLine(
      text: "  return Text('Hello');",
      type: CoreCodeDiffLineType.removed,
      lineNumber: 5,
    ),
    CoreCodeDiffLine(
      text: "  return Text('Hello').bodyMedium;",
      type: CoreCodeDiffLineType.added,
      lineNumber: 5,
    ),
  ],
)
```

`+` / `-` / 공백 prefix 는 CSS 가 아니라 실제 텍스트 콘텐츠라, 변경 여부를 색상 없이도 전달합니다 — 이 구조는 실제 변경이 있을 때만 의미가 있습니다.

</Callout>

---

### ❌ Don't

<Callout type="warning">

**변경 없는 단일 코드 블록 표시에 사용하지 않기**

```dart
// ❌ 변경 사항 없이 unchanged 라인만 나열
CodeDiff(
  lines: [
    CoreCodeDiffLine(
      text: 'final x = 1;',
      type: CoreCodeDiffLineType.unchanged,
      lineNumber: 1,
    ),
  ],
)

// ✅ 단일 코드 블록은 CodeSnippet
CodeSnippet(code: 'final x = 1;', mode: 'dart')
```

`CodeDiff` 는 코드/diff 시맨틱을 전혀 내보내지 않는(read-only, `<pre>`/`<code>`/`role="table"` 없음) 뷰어입니다 — 변경이 없는 코드에 쓰면 접근성 이점 없이 무게만 늘어납니다.

</Callout>

## 접근성 (Accessibility)

`CodeDiff` 는 편집 없는 뷰어입니다. `onLineTap` 이 없으면 표시용이고, 제공하면 행별 `Clickable` 활성화·포커스 표면이 추가됩니다.

### 역할

루트에 diff 전용 역할은 없습니다. 표시용 행은 일반 텍스트이며 `onLineTap` 행은 Flutter button 시맨틱 / Web `role="button"` 을 합성된 `Clickable` 에서 받습니다. `<pre>` · `<code>` · `<table>` · `<ins>` / `<del>` 의미는 자동으로 붙이지 않습니다.

즉 리더는 이 블록을 **일반 텍스트 흐름**으로 지나가며, diff 를 하나의 단위로
찾거나 건너뛸 수 없습니다.

### 키보드

표시용 행에는 키 처리가 없습니다. `onLineTap` 을 제공한 행은 Tab으로 도달하고 Enter / Space로 해당 라인을 활성화합니다.

### 포커스 관리

표시용 경로에는 포커스 가능한 요소가 없습니다. 활성 행은 Clickable의 포커스·링을 사용하며 루트에서 포커스를 가두거나 이동하지 않습니다.
Web 루트는 `overflow-hidden` 이고 행이 줄바꿈되므로(`whitespace-pre-wrap`),
포커스 가능한 래퍼가 필요한 스크롤 컨테이너도 생기지 않습니다.

### 스크린 리더

각 행은 순서대로 평평한 텍스트로 읽힙니다 — 라인 번호(`showLineNumbers` 가 켜져
있고 `line.lineNumber` 가 있을 때만), 그다음 `'+ '` / `'- '` / `'  '` prefix,
그다음 라인 텍스트.

**이 prefix 는 CSS 가 아니라 실제 텍스트 콘텐츠**입니다(양 플랫폼 동일). 덕분에
추가/삭제 구분이 색상에만 실려 있지는 않습니다. 다만 그 이상은 없어서, 나머지는
구분되지 않는 산문처럼 읽힙니다.

### 알려진 제약

- **Web 에 코드 시맨틱이 없습니다** (`<pre>` / `<code>` 미사용). 리더가 코드 읽기
  모드로 진입하지 않으므로 공백과 고정폭의 의미가 전달되지 않습니다.
- **diff 전용 시맨틱이 없습니다** — `<ins>` / `<del>` 도, "추가된 줄" 같은 행 단위
  `aria-label` 도 없습니다. 유일한 신호는 리터럴 `+` / `-` 문자이고, 이 문자를
  읽어줄지는 리더와 상세도(verbosity) 설정에 따라 달라집니다. 변경 없는 행의
  공백 두 칸 prefix 는 대개 통째로 무시됩니다.
- **라인 번호가 해당 라인과 연결되어 있지 않습니다** — 형제 텍스트 노드일 뿐이라
  "5번째 줄의 내용" 이라는 관계가 전달되지 않습니다.
- **diff 전체에 이름도 역할도 없습니다.** 랜드마크나 영역으로 찾아갈 수 없으므로,
  이름 붙은 영역이 필요하면 감싸는 쪽에서 직접 역할과 이름을 부여해야 합니다.

전역으로 적용되는 축(동작 줄이기·고대비·색 강제 모드·최소 터치 타겟)은
[전역 접근성 축](/accessibility)에 있습니다.

## 크로스 플랫폼 차이점 (Platform Differences)

| 항목 | Flutter | Web |
|------|---------|-----|
| 행 배치 | Column 안 Row · Expanded 텍스트 | 행·번호·prefix·본문 DOM 래퍼 |
| 추가·삭제 밴드 | 불투명 컨테이너 토큰 | 불투명 컨테이너 토큰 (행별 CSS 색으로 미리 계산) |
| 활성 행 | `Clickable` 의 Gesture/키보드 | `Clickable` 의 DOM/키보드 |
| 호스트 표면 | 호출부 래퍼 | `id` / 속성 / 이벤트를 OutlinedContainer 루트에 전달 |
| 폭 | `Column(crossAxisAlignment: stretch)` 라서 받은 폭을 채운다 | 루트가 블록이라 블록 부모에서는 폭을 채우고, flex 부모(행 · 가운데 정렬 열)에서는 내용 폭이다. 채우려면 호출자가 `classes: 'w-full'` 을 적는다 |
