# Flow Permutation: figma-contract-components

> 이 도구의 "사용자 플로우" = 플러그인 실행 경로. 상태 축: 파일 상태(신규/구 단일 페이지/최신) × 변경 종류(없음/docs만/축/렌더러) × 실패 지점. 전 경로와 처분:

| # | 경로 | 기대 동작 | 커버 |
|---|---|---|---|
| P-1 | 신규(빈) 파일에서 generate | 페이지 N+1 생성, 전량 빌드, 로그에 built×N | BDD 페이지 시나리오 |
| P-2 | 구 단일 페이지 파일에서 첫 실행 (대이동) | 배치 정규화가 전 노드 이동(key 보존), 빈 소스 페이지 remove | BDD 마이그레이션 |
| P-3 | P-2 중간 중단 후 재실행 | 이동된 것 skip·잔여만 이동 — 재실행=복구, 소스 페이지는 빌 때까지 보존 | BDD 부분 실패 |
| P-4 | 변경 없음 2회차 | 전 엔트리 skipped, 프레임 불변, 시간 <10% | BDD 멱등 |
| P-5 | docs 1건 수정 후 | 해당 엔트리만 rebuilt (per-entry hash) | BDD hash 입도 |
| P-6 | 렌더러/레이아웃 변경 (SCHEMA_REV bump) | 전역 재빌드 — 의도된 전량 무효화 | 아키텍처 T-15 |
| P-7 | 빌더 1개 throw | per-entry 트랜잭션 롤백, 그 페이지만 원상, 나머지 계속 (NFR-D) | 기존 메커니즘 승계 |
| P-8 | static→set 승격 실행 | 입양 rename→combine, 자식 key 불변 | BDD 승격 |
| P-9 | 수동으로 노드를 다른 페이지로 옮긴 뒤 실행 | 배치 정규화가 제자리로 복귀(자가 치유) | T-13 로그 |
| P-10 | 미등재/수동 노드가 구 페이지에 잔존 | 소스 페이지 보존 + 경고 로그 (임의 삭제 금지) | R-1 |
| P-11 | 다른 파일(비정본)에서 실행 | 기존 canonical-library 경고 후 계속 (선행 #3740 동작 불변) | 기존 |
| P-12 | 무료 플랜 파일(3페이지 제한) | 페이지 생성 실패 시 명시 에러 + README 안내 (조용한 부분 성공 금지) | FR-017 |
| P-13 | 섹션 분할 실행(예산 초과 모드) | 선택 섹션만 빌드 — 나머지 페이지 불변, 로그에 범위 명시 | R-3 |
| P-14 | verify 명령 | 기존 identity-idempotence 검증에 페이지 배치·key 대조 포함 | NFR-F |

**갭 판정**: 미커버 경로 0 — P-1~P-14 가 파일 상태 × 변경 × 실패 매트릭스를 소진(문서/예시 변경은 P-5, 축 변경은 P-6 이 아니라 per-entry rebuild 로 P-5 와 동형).
