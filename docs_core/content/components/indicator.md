# Indicator

`Indicator` 는 `child` 위젯/컴포넌트를 감싸고 그 모서리·가장자리에 `item` 을 띄우는 wrapper 입니다. 아바타 우상단의 온라인 점, 아이콘 우상단의 카운트 배지, 카드 좌상단의 "신규" 라벨 같은 패턴에 적합합니다.

## 사용 시기 (When to Use)

**이 컴포넌트를 사용하세요:**
- 아바타에 온라인 상태 점 (status dot) 을 표시할 때
- 아이콘 위에 알림 카운트 배지를 띄울 때
- 카드/이미지 위에 "신규" / "HOT" 라벨을 오버레이할 때

**대신 다른 컴포넌트를 사용하세요:**
- **[Badge](/components/badge)**: 다른 요소에 얹지 않고 인라인 상태·개수만 표시할 때
- **[DotIndicator](/components/dot-indicator)**: 코너의 항목 하나 대신 페이지 위치 목록·탐색이 필요할 때

## 위치 조합 (Position Matrix)

| | start | center | end |
|---|---|---|---|
| **top** | 좌상단 | 상단 가운데 | 우상단 (default) |
| **middle** | 좌측 가운데 | 정중앙 | 우측 가운데 |
| **bottom** | 좌하단 | 하단 가운데 | 우하단 |

`center` / `middle` 일 땐 `transform: translate(-50%, -50%)` (Web) 또는 `Align(alignment: Alignment(h, v))` (Flutter) 으로 anchor 를 자식의 중심에 맞춥니다.

## 동작 스펙 (Behavior)

- 표시 전용 wrapper. 인터랙션 없음.
- Flutter: `Stacks(clipBehavior: .none)` + `Position`. item 이 child 의 bounding box 를 넘어가도 잘리지 않음.
- Web: `position: relative; overflow: visible` 컨테이너 + `position: absolute` overlay div. 동일 시맨틱.
- **둘레(ring)**: item 바깥에 `ringWidth`(기본 2, `CoreStrokeWidth.stroke2`) 두께의 `ringColor`(기본 `surface`) 알약 둘레가 그려져 item 이 겹친 child 에서 오려 낸 것처럼 읽힙니다. 둘레는 item **바깥**으로 나갑니다 — item 의 모서리가 child 의 모서리와 만나고(`.end` + `.top` 이면 item 의 오른쪽 위 모서리 = child 의 오른쪽 위 모서리) 둘레만큼 바깥으로 튀어나옵니다. 그래서 child 의 크기와 상관없이 item 은 항상 그 모서리에 붙고, `offset` 은 그 기준에서 안쪽으로 겹치는 정도만 정합니다. 둘레의 모서리는 `ringBorderRadius`(기본 `CoreRadius.radius9999`, 알약)이고 두 플랫폼이 같은 필드를 읽습니다. `ringWidth: 0` 이면 둘레가 없습니다. Flutter 는 item 을 `ringWidth` 만큼 패딩한 알약으로 감싸고 anchor 를 같은 만큼 바깥으로 당기며, Web 은 overlay 에 `box-shadow: 0 0 0 <ringWidth> <ringColor>` 를 얹습니다.
- `indicatorStyle.offset` 은 양수일수록 item 이 child 안쪽으로 들어옴 — Flutter 는 `Position` 의 `top` / `right` / `bottom` / `left` 에 logical pixel 로, Web 은 같은 네 속성의 inline CSS 에 `offset / 16` 을 `rem` 으로 넣습니다 (`offset: 4` → `0.25rem`). 미지정 시 `CoreIndicatorTheme.style?.offset` → `CoreIndicatorStyle.defaultOffset` (`0`) 순으로 폴백.

## 사용 가이드라인 (Usage Guidelines)

### ✅ Do

<Callout type="tip">

**`item` 자체에 의미를 실어라**

```dart
Indicator(
  item: Badge(child: Text('안 읽음 3')),
  child: Icon(LucideIcons.bell),
)
```

이유: `Indicator` 자체는 표시 전용 wrapper 라 시맨틱 의미가 없습니다. `item` 위젯 자체가 (`Badge(child: Text('안 읽음 3'))`처럼) 실제 의미를 담아야 스크린 리더가 그 내용을 읽을 수 있습니다.

</Callout>

---

### ❌ Don't

<Callout type="warning">

**여러 개를 나열하는 용도로 사용 금지**

```dart
// ❌ Indicator 는 하나의 child 에 하나의 item 을 배치하는 wrapper
Row(
  children: List.generate(
    5,
    (i) => Indicator(item: const Status(), child: const SizedBox()),
  ),
)
```

이유: `Indicator` 는 `child` 하나를 감싸고 그 모서리에 `item` 하나를 띄우는 용도입니다. 캐러셀 위치처럼 여러 점을 나열해야 한다면 `DotIndicator` 를 사용해야 합니다.

</Callout>

## 접근성 (Accessibility)

### 역할

**양 플랫폼 모두 자체 role 이나 semantics 를 전혀 내보내지 않습니다.** Flutter 는 `Stacks(clipBehavior: .none)` 안에 `child` 와 `Position(item)` 을 나열할 뿐 `Semantics` 호출이 없고 (`indicator.dart:91-108`), Web 은 `configureAttributes` 를 override 하지 않아 바깥 `<div>` 에도 overlay `<div>` 에도 `role` / `aria-*` 가 하나도 붙지 않습니다 (`indicator.dart:82-100`).

즉 `Indicator` 는 순수 배치 wrapper 이고, **의미는 전적으로 `item` 과 `child` 자신이 들고 있어야 합니다** — `item: Badge(child: Text('안 읽음 3'))` 처럼 읽을 텍스트가 `item` 안에 있어야 스크린 리더가 그 뱃지를 안내할 수 있습니다.

### 키보드

처리하는 키가 없습니다. Flutter 생성자는 콜백 파라미터를 하나도 받지 않고 (`indicator.dart:25-32`), Web 은 `eventHandlers` 를 받긴 하지만 (`indicator.dart:26`) 루트에 `tabindex` 를 내보내지 않아 래퍼 자신에게는 포커스가 오지 않습니다 — 감싼 `child` 가 포커스 가능할 때 그 자식에서 버블링된 키 이벤트만 도달합니다.

### 스크린 리더

래퍼 자신에게서 나오는 이름은 없고, `child` 와 `item` 이 각자의 semantics 를 그대로 통과시킵니다.

**읽기 순서는 `child` → `item`** 입니다. 두 플랫폼 모두 `child` 를 먼저, 오버레이를 나중에 배치하기 때문입니다 (Flutter 는 `Stacks` 의 children 순서 `indicator.dart:93-106`, Web 은 DOM 순서 `indicator.dart:91-99`). 시각적으로는 뱃지가 콘텐츠 **위에** 겹쳐 보이지만, 안내는 "종 아이콘 → 3 unread" 순으로 콘텐츠 **뒤에** 옵니다.

상태 통보는 없습니다. `item` 이 바뀌어도 (뱃지 숫자가 늘어나도) 어느 쪽에도 live region 배선이 없어 조용히 교체됩니다.

### 포커스 관리

포커스 대상이 아닙니다. Flutter 에 `FocusNode` / `Focus` 가 없고 Web 에 `tabindex` 가 없어 어느 플랫폼에서도 traversal 정지점이 되지 않습니다. 오버레이 컴포넌트가 아니므로 진입·이탈·트랩 모두 해당 없습니다.

### 알려진 제약

- **오버레이를 장식으로 표시할 수단이 컴포넌트 쪽에 없습니다.** `CoreIndicatorContract` 는 `child` / `item` / 두 position / `indicatorStyle` 만 노출하고 (`indicator_contract.dart:16-33`), Web overlay `<div>` 에도 `aria-hidden` 이 붙지 않습니다 (`indicator.dart:93-98`). 순수 장식 점(`Status` 등)을 접근성 트리에서 빼려면 **`item` 쪽에서** 처리해야 합니다 — Flutter 는 `ExcludeSemantics` 로, Web 은 `aria-hidden` 을 실은 요소로 `item` 을 감싸세요.
- **`item` 값 변화가 통보되지 않습니다.** 읽지 않은 개수가 0 → 3 으로 바뀌어도 스크린 리더는 아무 말도 하지 않습니다. 변화를 알려야 한다면 통보 책임을 지는 컴포넌트(`Status` / `Toast` 등)를 `item` 자리에 두거나, 화면 쪽에서 별도 live region 을 마련해야 합니다.

모션 감소 · 고대비 · 최소 터치 타깃처럼 모든 컴포넌트에 공통으로 적용되는 축은 [전역 접근성 축](/accessibility) 에 정리되어 있습니다.

## 크로스 플랫폼 차이점 (Platform Differences)

| 항목 | Flutter | Web |
|------|---------|-----|
| 기반 | `Stacks(clipBehavior: .none)` + `Position` | `<div>` `position: relative` + `<div>` `position: absolute` |
| Center / Middle 정렬 | `Align(alignment: Alignment(h, v))` | `transform: translate(-50%, -50%)` |
| Offset 단위 | logical pixels | inline `rem` (`offset / 16` — Tailwind 클래스 아님). 루트 font-size 에 따라 스케일 |
