# Element-owned Web styles - #6403 / PR #6419

Button, Badge, Progress, Pagination, Disclosure, ChipInput, SidebarItem, SidebarSearch, SidebarHeader, SidebarRailItem, MenuItem, Breadcrumb, OptionItem and CommandSearch previously derived global CSS scopes from a local key or a reusable component configuration. Different owners could therefore share a scope and apply one instance's existing styles to another. The fourteen types now use the actual Jaspr Element's lifetime through an unexported `@internal` Expando helper. Separate `ssr` and `web` namespaces keep static server owners distinct from newly mounted client owners.

Public constructors, const markers, fields, explicit caller-ID precedence, keys, caller classes/CSS ordering and events remain unchanged. Generated private IDs/classes, selectors and their internal references change. Core, Native, resolver arguments/defaults, SDK, locks, manifest producers, comparison criteria and baselines are unchanged by this PR. The direct meta dependency and html dev dependency use the same existing resolved versions and all 232 package entries; no lint suppression or package upgrade is used.
