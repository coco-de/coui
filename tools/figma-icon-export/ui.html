CoUI Icon Export

1) Select your logo component on the canvas (not an instance). 2) Pick a background color. 3) Generate. This builds a 36-variant App Icon + Splash Screen matrix (iOS/Android/macOS/Windows/ Linux × Production/Development/Staging) on an "App Icon Export" page, with real Android/iOS safe-zone rules already applied.

Export every variant as a PNG named after its real shipped code asset (e.g. ic_foreground_dev.png, splash_logo_android12.png) — no manual renaming. The safe-zone guide is always force-hidden at export time, regardless of its current toggle state.
