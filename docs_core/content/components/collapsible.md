## 구조

머리 줄(`trigger`)과 본문(`content`) 두 슬롯이 전부입니다. 화살표는 컴포넌트가 그립니다.

</AnatomyItem>

</AnatomyItem>

`trigger` 슬롯. 기본 글자는 `bodyMedium` · 500 · `onSurface`이고, 마우스를 올리면 밑줄이 생깁니다.

</AnatomyItem>
<AnatomyItem part="leading" name="chevron" side="right">

열림 표시. 16 크기, `onSurface`이고 열리면 180° 돌아갑니다. 머리 글자와의 사이는 16입니다.

</AnatomyItem>

</AnatomyItem>

### 머리 줄에 다른 것 두기

`trigger`에는 글자 대신 다른 위젯 · 컴포넌트를 넣을 수 있습니다. 화살표는 그대로 줄 끝에 붙습니다. Flutter에서 폭을 정하지 않은 자리의 제약은 [배치](#배치)를 보세요.

## 상태

<Preview demo="collapsible/states" />

| 상태 | 화면 |
| --- | --- |
| 접힘 | 본문이 보이지 않고 화살표는 아래를 봅니다. |
| 펼침 | 본문이 보이고 화살표가 180° 돌아갑니다. |
| 마우스를 올림 | 머리 글자에 밑줄이 생깁니다. Flutter는 머리 줄 어디에 올려도, Web은 머리 글자 영역에 올릴 때만 생깁니다. |
| 키보드 포커스 | 머리 줄에 포커스 링을 그립니다. |

비활성 상태를 만드는 속성은 없습니다.

<a id="동작-스펙-behavior"></a>

### 인터랙션

머리 줄을 누르거나, 머리 줄에 포커스를 두고 `Enter` · `Space`를 누르면 여닫습니다.

<a id="기본-닫힘-상태로-시작"></a>
<a id="기본-펼침"></a>

### 상태 전환

`onExpandedChanged`를 넘기는지에 따라 누가 열림을 정하는지가 달라집니다.

| 경우 | 누르면 | `expanded` |
| --- | --- | --- |
| 콜백 없음 | 컴포넌트가 스스로 여닫습니다. | 처음 상태(기본 `false`)입니다. 나중에 다른 값을 넘기면 그 값을 따릅니다. |
| 콜백 있음 | 콜백에 바뀔 값만 알립니다. | 코드가 이 값을 바꿔야 여닫힙니다. 바꾸지 않으면 화면도 그대로입니다. |

```dart
Collapsible(
  trigger: Text('필터'),
  content: FilterPanel(),
  expanded: isFilterOpen,
  onExpandedChanged: (value) => setState(() => isFilterOpen = value),
)
```

### 애니메이션

본문 높이와 화살표 회전이 200ms(`CoreDuration.normal`) 동안 함께 움직입니다. 본문은 `CoreEasing.move`를 따르고, 화살표는 Web이 같은 곡선, Flutter가 일정한 속도로 돕니다. Web에서는 본문 위의 16 여백이 전환 없이 열 때 바로 붙고 닫을 때 바로 빠집니다. 시간은 `collapsibleStyle.duration`으로 바꿉니다. 동작 줄이기를 켜면 두 플랫폼 모두 500ms 이하의 전환은 바로 바뀝니다.

## 사용 가이드

보조 설명, 추가 옵션, 긴 약관처럼 평소에는 숨겨 두었다가 필요할 때 펼치는 영역 하나에 씁니다.

### 다른 컴포넌트가 더 맞는 경우

| 이런 경우에는 | 대신 쓸 것 |
| --- | --- |
| 여러 섹션 가운데 하나만 열려야 할 때 | [Accordion](/components/accordion) |
| 웹에서 스크립트 없이도 열려야 할 때 | [Disclosure](/components/disclosure) |
| 계층 구조의 가지를 여닫을 때 | [Tree](/components/tree) |
| 머리 줄 없이 영역을 숨기고 보일 때 | [Hidden](/components/hidden) |

### 꼭 보아야 할 내용은 접지 않기

<Split>

<Code language="dart" title="이렇게 하세요">
// 대부분의 사용자가 바꾸지 않는 설정을 접어 둡니다.
Collapsible(
  trigger: Text('고급 설정'),
  content: AdvancedSettingsPanel(),
)
</Code>

<Code language="dart" title="이렇게 하지 마세요">
// 결제 오류는 접어 두지 말고 바로 보여 주세요.
Collapsible(
  trigger: Text('결제 오류'),
  content: Text('카드 정보가 맞지 않습니다.'),
)
</Code>

</Split>

한 줄짜리 내용은 접지 않고 그대로 보여 주는 편이 낫습니다. 섹션마다 따로 열려야 하면 `Collapsible`을 섹션 수만큼 두고, 열림을 각각 관리합니다.

## 배치

| 플랫폼 | 폭 |
| --- | --- |
| Flutter | 부모가 폭을 정해 주지 않으면 머리 줄과 본문 가운데 더 넓은 쪽의 폭이 됩니다. 부모가 폭을 정해 주면 그 폭을 씁니다. |
| Jaspr Web | 내용 폭입니다(`inline-flex`). 세로 flex 부모가 늘여 맞추면(stretch) 부모 폭을 채우고, 블록 부모에서 폭을 채우려면 `classes: 'w-full'`을 둡니다. |

<Note>

Flutter에서는 폭을 정해 주지 않은 자리에서 내용의 폭을 먼저 잽니다. 이때 머리 줄이나 본문에 `LayoutBuilder`처럼 자기 폭을 미리 알려 주지 못하는 위젯이 있으면 레이아웃 오류가 납니다. 그런 위젯을 넣을 때는 `Collapsible`의 폭을 정해 주세요.

</Note>

<a id="스타일-시스템-style-system"></a>

## 테마와 스타일

겉모습은 `collapsibleStyle`(`CoreCollapsibleStyle`) 하나로 정합니다.

| 바꾸는 곳 | 필드 | 기본값 |
| --- | --- | --- |
| 여백 | `contentInset` | 사방 16 |
| 머리 글자 | `triggerTextStyle` | `bodyMedium` · 500 · `onSurface` |
| 본문 글자 | `contentTextStyle` | `bodyMedium` · `onSurface` |
| 화살표 | `iconStyle` · `iconLabelGapStyle` | 16 · `onSurface` · 간격 16 |
| 전환 | `duration` | 200ms |
| 포커스와 누름 | `clickableStyle` | 누를 때 줄어들지 않음 |

`contentInset`은 머리 줄에는 사방에, 본문에는 `top`만 적용됩니다. 그래서 기본값에서는 본문이 머리 글자보다 16 왼쪽에서 시작합니다. 같은 선에 맞추려면 `content`에 좌우 여백을 직접 둡니다.

### 값이 정해지는 순서

뒤로 갈수록 우선합니다.

```text
디자인 시스템 기본값
  → CoreComponentTheme.collapsible.style   // 앱 전체
  → collapsibleStyle                       // Collapsible 하나
```

<a id="접근성-accessibility"></a>

## 접근성

### 역할

| 플랫폼 | 역할 |
| --- | --- |
| Flutter | 머리 줄은 버튼이고 펼침 상태(`Semantics(expanded:)`)를 함께 알립니다. |
| Jaspr Web | 머리 줄은 `role="button"` · `tabindex="0"` · `aria-expanded`입니다. 바깥 `<div>`에는 역할이 없습니다. |

두 플랫폼 모두 머리 줄과 본문을 잇는 `aria-controls`와 본문의 `region` 역할은 없습니다.

### 키보드

| 키 | 동작 |
| --- | --- |
| `Tab` · `Shift+Tab` | 머리 줄에 한 번 멈춥니다. 펼친 본문의 요소는 그 뒤에 이어집니다. |
| `Enter` · `Space` | 여닫습니다. |
| `Escape` | 처리하지 않습니다. |

### 스크린 리더

- 머리 줄의 이름은 `trigger`에 넣은 내용입니다. 아이콘만 넣으면 이름이 없는 버튼이 되니 글자를 함께 두세요.
- Web은 접힌 본문이 읽히지 않습니다. Flutter는 접힌 본문을 접근성 트리에서 빼는 처리를 따로 하지 않습니다. 화면 밖으로 잘려 빠지는 경우가 많지만, `ListView`의 항목이나 `Semantics(container: true)` 안에서는 접힌 본문의 글자도 읽힙니다.
- 여닫은 결과를 따로 알리지 않습니다. 펼침 상태는 머리 줄에 붙어 있습니다.

### 포커스 관리

- 여닫을 때 포커스를 옮기거나 가두지 않습니다.
- 접힌 본문 안의 요소는 Tab 순서에서 빠집니다. Flutter는 접히는 전환이 끝나면, Web은 닫는 순간에 빠집니다.
- 본문 안에 포커스가 있는데 닫히면, Flutter는 전환이 끝난 뒤 본문 밖에서 직전에 포커스가 있던 곳으로 돌립니다. Web은 포커스를 되돌리지 않습니다.

### 알려진 제약

| 플랫폼 | 내용 |
| --- | --- |
| Jaspr Web | 머리 줄과 접히는 상자에 속성을 덧붙일 방법이 없어 `aria-controls`를 밖에서 더할 수 없습니다. `attributes`는 바깥 `<div>`에만 붙습니다. |
| Flutter | `ListView`의 항목이나 `Semantics(container: true)` 안에서는 접힌 본문의 글자도 읽힙니다. |

> 동작 줄이기 · 고대비 · 색 강제 모드 · 최소 터치 영역처럼 모든 컴포넌트에 걸리는 내용은 [접근성](/accessibility) 페이지가 다룹니다.

<a id="크로스-플랫폼-차이점-platform-differences"></a>

## 플랫폼 차이

| 항목 | Flutter | Jaspr Web |
| --- | --- | --- |
| 부모가 폭을 정하지 않을 때 | 내용의 폭 | 내용의 폭(`inline-flex`) |
| 펼침 전환 | `SizeTransition` | CSS `grid-template-rows` 전환 |
| 접힌 본문을 Tab 순서에서 빼는 때 | 접히는 전환이 끝난 뒤(`ExcludeFocus`) | 닫는 순간(`inert`) |
| 접힌 본문과 스크린 리더 | 놓인 자리에 따라 읽힐 수 있습니다. | 읽히지 않습니다. |
| 포커스가 든 본문이 닫힐 때 | 직전 위치로 돌립니다. | 되돌리지 않습니다. |
| 화살표 회전 | 일정한 속도 | `CoreEasing.move` |
| 밑줄이 생기는 영역 | 머리 줄 전체 | 머리 글자 영역 |
| 본문 위 여백의 전환 | 높이와 함께 움직입니다. | 바로 붙고 바로 빠집니다. |
| 웹 전용 속성 | — | `id` · `classes` · `css` · `attributes` · `eventHandlers`와 `onClick` 같은 이벤트 파라미터 |

<a id="props-parameters"></a>

## API

`W`는 Flutter에서는 `Widget`, Jaspr Web에서는 `Component`입니다.

### 생성자

| 이름 | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `trigger` | `W` | 필수 | 머리 줄의 내용 |
| `content` | `W` | 필수 | 펼쳤을 때의 본문 |
| `expanded` | `bool` | `false` | 처음 상태. `onExpandedChanged`를 넘기면 이 값이 열림을 정합니다. |
| `onExpandedChanged` | `void Function(bool)?` | `null` | 머리 줄을 눌렀을 때 바뀔 값을 알립니다. |
| `collapsibleStyle` | `CoreCollapsibleStyle?` | `null` | 겉모습 · 전환 시간 |

### 그 밖의 멤버

- `withStyle(CoreCollapsibleStyle patch)` — `collapsibleStyle`에 `patch`를 합친 사본을 돌려줍니다.
- `copyWith(…)` — 바꾼 값으로 사본을 만듭니다.
- Web은 `id`(HTML id) · `classes` · `css` · `attributes` · `eventHandlers` 같은 HTML 속성과 `onClick` 같은 이벤트 파라미터도 받습니다.

<!-- STYLE_TABLE:BEGIN — auto-generated by `dart run tool/generate_style_tables.dart` (write mode). Do not hand-edit between these markers; edit the CoreXxxStyle source and regenerate. -->

### `CoreCollapsibleStyle` 필드

| 필드 | 타입 | 설명 |
|------|------|------|
| `contentInset` | `CoreEdgeInsets?` | Inner inset around the trigger and the content area (pre-scaling). |
| `duration` | `Duration?` | Expand/collapse animation duration. |
| `triggerTextStyle` | `CoreTextStyle?` | Trigger row text style override. |
| `contentTextStyle` | `CoreTextStyle?` | Content body text style override. Layered over the `bodyMedium` typography role + on-surface colour the widget composes for the expanded content area (single static site, no state branch). |
| `iconLabelGapStyle` | `CoreGapStyle?` | Horizontal gap slot between the trigger text and the chevron icon. Forwarded straight to `Gap(gapStyle: …)` (Flutter) and to the gap `<div>` width (Web). |
| `iconStyle` | `CoreIconStyle?` | Chevron / disclosure icon style. |
| `clickableStyle` | `CoreClickableStyle?` | Style of the trigger's `Clickable` — press scale, focus ring, transition durations. Merged on top of [defaultClickableStyle] and passed to the `Clickable` as is; the `Clickable` fills whatever is left unset from its own defaults. |

<!-- STYLE_TABLE:END -->

<Note>

`contentInset`은 머리 줄의 사방과 본문의 위쪽에만 적용됩니다. `contentTextStyle`은 본문의 글자가 물려받는 값이고, `iconLabelGapStyle`은 두 플랫폼 모두 머리 글자와 화살표 사이의 간격입니다. `clickableStyle`은 머리 줄의 누름 반응과 포커스 링을 바꿉니다.

</Note>
