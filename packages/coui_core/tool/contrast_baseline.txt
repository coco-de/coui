## Scrollbar thumb in CoUI high-contrast light (UI line bar, 4.5:1) — a recorded exception, not debt
# reason: the thumb is the page ink at half strength, which measures 3.95:1
# on the page and on the panel fill in this mode. That clears the component
# bar (WCAG 1.4.11, 3:1) and misses the raised 4.5:1 the mode holds UI lines
# to. It is accepted by design decision, because the two ways to close it
# both cost more than the gap: a component does not read whether high
# contrast is on (the theme axis applies at the token-resolution seat and
# nowhere else), and the way to give this one thumb an opaque ink in this
# mode is a slot of its own — which Web cannot express as "alpha in light,
# opaque here", since its colour variables hold the RGB triplet only — and
# which would also give up what the translucent ink buys: a thumb that stays
# one step darker than whatever it sits on, grey containers and panels
# included. These entries leave when colour variables can carry alpha or
# the mode can state an opaque thumb; they do not leave by loosening the
# bar. The high-contrast dark table meets 4.5:1 on both tones (5.28, 4.73).
coui high-contrast light scrollbar/thumb on surface rest (>=4.5)
coui high-contrast light scrollbar/thumb on surface-bright rest (>=4.5)

## RadioGroup card selected tile description under the state-layer wash — a recorded exception, not debt
# reason: a `card` tile lays the halo's ink (`onSurface`) at the hover (8%)
# and pressed (16%) weights over its whole face, and the description is the
# second text tier (`onSurfaceVariant`) on that face. The selected tile's
# face is `primaryContainer` (the designer's choice, #5634), which sits closer
# to the description's ink than the resting `surface` does. The title
# (`onSurface`) keeps its margin under both washes, and the description
# clears 4.5:1 at rest on both faces in every scheme (5.64 light, 5.04 dark
# on the selected tile in CoUI). Under the wash it measures 4.12:1 (light) /
# 3.25:1 (dark) pressed and 4.03:1 (dark) hovered on the selected tile in
# CoUI. The standard mapping joined the same class with the selected-face
# gap contract (#6202): on the audited palette it moves `primaryContainer`
# one step away from the page in both modes (gap 1.19 → 1.34 light,
# 1.24 → 1.81 dark), and the description under the wash then measures
# 4.41:1 (light) / 3.61:1 (dark) pressed and 4.49:1 (dark) hovered. The
# contract's own text conditions on the face — `onPrimaryContainer` 4.5:1,
# `primaryText` 3:1 — pass there, and the description clears 4.5:1 at rest.
# The high-contrast schemes clear it. The wash
# is the weight every radio presses at and the description's tier is what
# separates it from the title, so closing the gap means a lighter wash or a
# louder description on the selected face, and either blurs what it
# separates. Accepted pending the design decision recorded in #5634 (the
# hover entry is new with the `primaryContainer` face). These entries leave
# when the tile's wash, its selected face or the description's ink is
# restated.
coui dark radio-group/card description on selected tile hover (>=4.5)
coui dark radio-group/card description on selected tile pressed (>=4.5)
coui light radio-group/card description on selected tile pressed (>=4.5)
standard dark radio-group/card description on selected tile hover (>=4.5)
standard dark radio-group/card description on selected tile pressed (>=4.5)
standard light radio-group/card description on selected tile pressed (>=4.5)
