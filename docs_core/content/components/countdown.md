# Countdown

숫자 값(기본 범위 0-99)을 표시하는 디스플레이 컴포넌트입니다. 값이 변경될 때 전환 애니메이션이 적용됩니다. 타이머 로직은 부모 컴포넌트에서 관리합니다.

## 사용 시기 (When to Use)

**이 컴포넌트를 사용하세요:**
- 카운트다운 숫자를 크게 표시할 때
- 시간 단위별 숫자를 개별 표시할 때 (시:분:초 각각)
- 세션 타임아웃 등 남은 시간을 숫자로 표시할 때

**대신 다른 컴포넌트를 사용하세요:**
- **[NumberTicker](/components/number-ticker)**: 클램핑한 정수 교체 대신 숫자 값 사이를 보간해야 할 때
- **[Progress](/components/progress)**: 숫자 표시 대신 진행값을 비율로 시각화할 때

### 네 단위의 공통 너비 — 호출부 조합

`Countdown`은 정수 하나만 그립니다. Days · Hrs · Min · Sec의 상자와 단위는 호출부에서 조합하고, 네 상자는 **W = max(size/56, 가장 넓은 숫자 폭 + space/8 + space/8)**을 함께 사용합니다. 타이포와 밀도를 바꾸면 현재 토큰과 글자 치수로 다시 배치합니다. 고정된 56.6이나 자릿수별 추정 폭을 저장하지 않습니다.

실행 가능한 호출부 예제: [Flutter 소스](https://github.com/coco-de/coui/blob/main/docs_core/lib/previews/examples/flutter/countdown/countdown_units_example.dart), [Web 소스](https://github.com/coco-de/coui/blob/main/docs_core/lib/previews/examples/web/countdown/countdown_units_example.dart). 두 예제가 사용하는 상자 스타일은 [공유 예제 토큰](https://github.com/coco-de/coui/blob/main/docs_core/lib/shared/countdown_units_sample.dart)에 있습니다. 기존 단일 숫자 Live Preview와 별도로 테스트하는 문서용 조합이며, 라이브러리의 새 컴포넌트 API는 아닙니다.

- Flutter는 `IntrinsicWidth` 안의 `Row`에 같은 flex의 `Expanded` 칸 네 개를 둡니다. 각 칸은 최소 56이고, 행은 가장 넓은 칸의 내용이 차지하는 폭을 네 칸에 동일하게 배분합니다. 갭은 별도 `Gap`입니다.
- Web은 `width: max-content`인 `inline-grid`에 `repeat(4, 1fr)`을 적용합니다. 부모의 전체 폭을 채우지 않고, 가장 넓은 칸을 기준으로 네 트랙이 함께 커집니다. [Figma의 HUG grid는 FLEX 트랙을 허용하지 않으므로](https://developers.figma.com/docs/plugins/api/GridTrackSize/) 이 CSS가 Figma 구현의 근거가 되지는 않습니다.
- 예제는 `Countdown(value: days, max: 365)`로 100 이상을 허용합니다. `max`를 생략하면 100이 99로 클램핑됩니다. 나머지 세 값은 8 · 30 · 15이며, 최소 API가 그리는 그대로 `8`을 표시합니다(앞에 0을 붙이는 포맷 API는 없습니다).
- 숫자는 기존 tabular figures를 유지합니다. 101→100과 99→98에서 폭을 유지하고, 100→99 경계에서는 숫자와 여백을 합한 폭이 최소 56을 넘을 때 네 칸이 함께 줄어듭니다. Flutter는 나가는 숫자의 페이드가 끝날 때까지 그 숫자의 폭도 유지합니다.

이 예제의 짧은 Body/XS 단위는 숫자용 내부 폭 안에 들어갑니다. 단위를 번역하거나 스타일을 바꾸면 단위의 넘침도 확인하세요. 좁은 부모에서는 행 자체를 스크롤할 공간을 제공해야 합니다. 네이티브 Figma 빌더의 후속 텍스트 편집·모드 변경에 따른 공통 확장은 아직 구현되지 않았으며, 런타임 예제의 통과로 그 작업을 완료 처리하지 않습니다.

## Props / Parameters

| 속성 | 타입 | 기본값 | 설명 |

## 동작 스펙 (Behavior)

### 인터랙션

- Countdown은 표시 전용 컴포넌트입니다. 인터랙션 없음.
- 부모 컴포넌트에서 Timer로 `value`를 업데이트해야 합니다.
- `value.clamp(min, max)` 의 정수만 표시하며 자체 타이머·완료 콜백·단위·비활성 상태는 없습니다. 숫자가 초인지 분인지는 호출부가 정합니다. `min <= max` 를 보장하세요.

### 애니메이션

- Flutter: `AnimatedSwitcher` + `FadeTransition`으로 값 변경 시 페이드 전환
- Web: CSS transition 규칙은 있지만 텍스트 변경을 두 노드 간 페이드로 교체하는 상태는 없습니다
- 양쪽 모두 `countdownStyle.animationDuration`(기본 `CoreDuration.fast` 150ms)을 씁니다

## 사용 가이드라인 (Usage Guidelines)

### ✅ Do

<Callout type="tip">

**시:분:초처럼 자릿수 단위로 인스턴스를 나눠서 표시**

```dart
Row(
  children: [
    Countdown(value: hours),
    Text(':'),
    Countdown(value: minutes),
    Text(':'),
    Countdown(value: seconds),
  ],
)
```

`Countdown`은 `min`(기본 0)~`max`(기본 99) 범위의 두 자릿수 값 하나만 표시하도록 설계되어 있습니다 — 더 큰 시간 단위를 표현하려면 단위별로 인스턴스를 나눠야 합니다.

</Callout>

---

### ❌ Don't

<Callout type="warning">

**Countdown 내부에 타이머 로직이 있다고 기대하지 않기**

```dart
// ❌ value를 한 번만 넘기고 자동으로 줄어들 거라 기대
Countdown(value: 60)
```

`Countdown`은 표시 전용 컴포넌트로 인터랙션도 내부 타이머도 없습니다 — 부모 컴포넌트가 `Timer`로 `value`를 직접 갱신해야 카운트다운이 동작합니다.

</Callout>

## 접근성 (Accessibility)

`Countdown` 은 표시 전용입니다 — 포커스를 받지 않고, 값 갱신은 부모가 합니다.
접근성 표면은 "바뀐 숫자를 읽어주는 것" 하나뿐입니다.

### 역할

- **Flutter** — `Semantics(liveRegion: true, label: <클램핑된 값>)`. 버튼·이미지 같은
  역할 플래그는 세우지 않고 live region 만 겁니다.
- **Web** — `<span>` 에 `aria-live="polite"` + `aria-label="<클램핑된 값>"`. `role` 은
  내보내지 않습니다.

### 키보드

없음. 양 플랫폼 모두 탭 순서에 들어가지 않고(Web 루트에 `tabindex` 가 붙지 않습니다)
처리하는 키도 없습니다.

### 스크린 리더

- **이름** — `value.clamp(min, max)` 결과 문자열 그 자체입니다. Flutter 는
  `Semantics(label:)`, Web 은 `aria-label` 에 같은 값을 넣으므로 리더가 읽는 숫자는
  화면의 숫자와 항상 같습니다.
- **통보** — 양 플랫폼 모두 live region 입니다. 값이 바뀔 때마다 polite 로 읽힙니다
  (Flutter `liveRegion: true`, Web `aria-live="polite"`).

### 포커스 관리

없음. 오버레이가 아니고 포커스 가능 요소도 아니라 진입·이탈·트랩이 모두
해당되지 않습니다.

### 알려진 제약

- **읽히는 것은 숫자뿐입니다.** 단위나 대상("42초 남음")을 넣을 파라미터가 없습니다 —
  contract 는 `value` / `min` / `max` / `countdownStyle` 만 노출합니다.
  대안: 맥락은 인접한 텍스트로 제공합니다.
- **live region 을 끄는 파라미터가 없습니다.** 부모가 1초마다 `value` 를 갱신하면
  리더도 1초마다 통보합니다. 대안: 갱신 주기를 부모에서 조절합니다.
- **Web 은 `aria-live` / `aria-label` 을 호출자가 넘긴 `attributes` 보다 나중에 병합합니다.**
  대부분의 Web 컴포넌트는 호출자의 `attributes` 가 이기지만 이 두 키만은 컴포넌트가
  이겨서, `attributes: {'aria-label': '...'}` 는 무시됩니다. 대안 없음.
- **토큰이 아닌 `animationDuration` 은 Web 에서 '동작 줄이기'를 빠져나갑니다.**
  기본값(`CoreDuration.fast`)이나 스케일 위 값은 `var(--coui-duration-*)` 로 나가
  `prefers-reduced-motion` 이 0 으로 덮지만, 스케일 밖 값(예
  `Duration(milliseconds: 175)`)은 리터럴 `175ms` 로 나가 그대로 재생됩니다.
  Flutter 는 값과 무관하게 `resolveMotionDuration` 을 거칩니다.
  대안: `CoreDuration` 의 alias(`fast` / `normal` / `moderate`)나 `msN` 스케일 값을 씁니다.
