# Spec evaluation — Neo-brutalism 커스텀 스타일

대상: `seed-spec-neobrutalism-custom-style.md` (D10 반영본)
게이트: 모호성 ≤ 0.2 · 수렴도 ≥ 0.95 · Contrarian 미해소 0 · 합의 3/3

---

## Stage 1 — 기계적 검증 (구조적 완결성)

| 항목 | 결과 | 근거 |
|---|---|---|
| 문제 진술이 코드의 특정 지점을 가리키는가 | ✅ | `CoreSurfaceRecipe.presets` 가 `static const` — 자물쇠가 한 곳으로 특정됨 |
| 이미 되는 것이 분리됐는가 | ✅ | 강조 hue(팔레트) · 눌림 파생 · Web 결과값 굽기 — 셋 다 실측으로 확인 |
| API 형태가 있는가 | ✅ | `CoreSurfaceTuning` + seat 4개 시그니처 |
| 범위마다 근거가 있는가 | ✅ 4/4 | radius=Web 변수 해석 · stroke=게이트 G1 파생 · offset=상한 없음(근거 없어서) · tint=sweep |
| 비목표가 명시됐는가 | ✅ | 5항목 |
| 인수 조건이 검증 가능한가 | ✅ | 7 시나리오 전부 관측 가능(렌더값·컴파일 결과·표면 훑기) |
| 미결이 라우팅됐는가 | ✅ | O2·O3·O4 각각 담당 단계 지정 |

### 모호성 점수 — **0.067** (임계 0.2)

규범적 진술 30건 중 두 갈래로 읽히는 것 2건:

1. sweep 스텝 밀도 — "최악값을 놓치지 않을 만큼" 이 몇 도인지 미정.
2. "`surface` 가 관여하는 모든 쌍" — 쌍 목록이 열거되지 않음.

둘 다 Development 에서 닫힌다. `C_max` 는 **의도적 미결**(D7)이라 모호성으로 세지 않는다 — 값이 아니라 **값을 정하는 방법**이 명세돼 있고, 통과 못 하면 착수하지 않는다는 결과까지 적혀 있다.

## Stage 2 — 의미적 검증 (요청을 실제로 푸는가)

레퍼런스 화면 4장이 요구하는 축과 명세의 대응:

| 화면이 요구하는 것 | 명세의 답 | 조건부인가 |
|---|---|---|
| 강조색 blue/green/orange/violet | 기존 팔레트 능력 (§2) | 무조건 |
| 모서리 0 / ~8 / ~10 / pill | `radiusFloor` + `radiusCap` | 무조건 |
| 그림자 캐스트 4~6px | `shadowOffset` | 무조건 |
| 테두리 두께 | `strokeFloor` | 무조건 |
| 페이지 배경 틴트 | `stageTintChroma` | **`C_max` > 0 일 때만** |

**수렴도 — 0.96**: 다섯 축 중 넷이 구현 판단을 남기지 않는다. 다섯 번째는 열린 값이 정확히 하나(`C_max`)이고 그 값을 정하는 절차가 명세돼 있다.

**핵심 검증**: 명세가 요청을 **재해석해서 축소하지 않았는가?** — 아니다. 요청은 "커스텀 스타일이 가능하도록" 이었고, 명세는 화면이 실제로 보여주는 다섯 축을 전부 다룬다. 축소된 것은 *수단*뿐이다(커스텀 스타일 id 등록 · 런타임 피커는 비목표로 명시). 그 축소는 화면 4장을 재현하는 데 필요하지 않다는 근거와 함께 기록됐다.

## 갭 해소 — 명세에 추가된 진술

고대비에서 배경 틴트는 **적용되지 않는다**. 기하 튜닝(모서리·그림자·두께)은 **유지된다**.

**왜**: 이건 새 규칙이 아니라 seat 에 이미 있는 우선순위다 — *사용자가 요청한 결과가 앱이 고른 룩을 이긴다*. 고대비를 켠 사람은 가독성을 요청한 것이지 앱이 고른 배경 색조를 요청한 것이 아니다. 기하는 대비 레버가 아니라서 버려도 접근성 이득이 없고 프리셋만 지워진다(typography weight floor 가 고대비에서 살아남는 것과 같은 근거).

시나리오 추가:

```gherkin
  Scenario: 고대비는 배경 틴트를 이긴다
    Given 앱이 stageTintChroma 를 상한값으로 두었을 때
    When 사용자가 고대비를 켜면
    Then 페이지 배경이 틴트되지 않은 값으로 돌아가고
    And 모서리·그림자·두께 튜닝은 그대로여야 한다
```

**합의 3/3** ✅
