# TrendChart

시간에 따라 변하는 값 하나를 선(`line`) 또는 막대(`bar`)로 그리는 컴포넌트입니다. 기간 칩(7일 · 30일 · 12개월), 요약 슬롯(보통 `Stat`), 목표 · 예산 같은 점선 기준선을 한 덩어리로 배치합니다. 데이터와 모든 표시 문자열은 호출자가 넘기고, 차트는 그 위치만 정합니다.

## 사용 시기 (When to Use)

**이 컴포넌트를 사용하세요:**
- 구독자 · 사용량 · 환율 · 매출처럼 한 지표가 시간에 따라 어떻게 움직였는지 보여 줄 때
- 기간을 바꿔 가며 같은 지표를 다시 볼 때(기간 칩)
- 목표나 예산 대비 현재 위치를 함께 보여 줄 때(기준선)

**대신 다른 컴포넌트를 사용하세요:**
- `Stat`: 추이 없이 현재 값과 변화율만 보여 줄 때
- `Tracker`: 기간별 상태(정상 · 경고 · 장애)를 색 구간으로 보여 줄 때
- `Progress`: 단일 작업의 완료 비율

## 스타일 시스템 (Style System)

겉모습(색 · 크기 · 간격)은 모두 `trendChartStyle` 하나로 넣습니다. 프로젝트 공통 값은 `CoreComponentTheme.trendChart` 의 `style` / `variantStyles` 에 둡니다.

```text
CoreTrendChartStyle.default*
  → CoreTrendChartTheme.style                     // 프로젝트 공통
  → CoreTrendChartTheme.variantStyles[variant]    // variant 별
  → widget.trendChartStyle                        // 인스턴스별
```

기간 칩의 모양은 `periodChipStyle`(`CoreChipStyle`)로 `Chip` 에 그대로 전달됩니다.

## 변형 (Variants)

### line

점마다 같은 폭의 구간 중앙을 지나는 선을 그리고, 마지막 점에 표식을 둡니다. 값 축은 데이터 범위에 맞춰 좁게 잡혀 작은 움직임도 보입니다.

### bar

점마다 막대 하나를 0 기준선에서 그립니다. 막대 길이가 곧 값이므로 값 축은 항상 0 을 포함합니다. 음수 막대는 아래로 자라고, 둥근 모서리는 기준선 반대쪽 끝에만 붙습니다.

## 동작 스펙 (Behavior)

### 인터랙션

각 점은 그래프 높이 전체를 차지하는 구간을 갖고, 그 구간에 마우스를 올리면 `Tooltip` 이 「날짜, 값」을 보여 줍니다. 기간 칩을 누르면 `onPeriodChanged` 가 그 인덱스로 호출됩니다 — 선택 상태와 데이터 교체는 호출자가 합니다.

### 상태 전환

`points` 가 비면 그래프 자리에 `empty` 슬롯을 그립니다(없으면 아무것도 그리지 않음). 요약 슬롯과 기간 칩은 그대로 남아 다른 기간을 고를 수 있습니다. 로딩 중에는 호출자가 같은 자리에 `Skeleton` 을 넣습니다.

### 축

값 축은 데이터와 기준선을 모두 담도록 1 · 2 · 5 × 10ⁿ 간격으로 반올림되고 눈금 수는 `axisTickCount`(기본 4 구간)를 목표로 합니다. 날짜 축은 첫 · 가운데 · 마지막 점의 라벨만 시작 · 가운데 · 끝에 붙입니다 — 어떤 폭과 글자 크기에서도 라벨이 겹치지 않고, 나머지 날짜는 툴팁과 스크린 리더로 읽을 수 있습니다. 값 축 라벨이 `plotHeight` 보다 더 많은 높이를 필요로 하면(큰 글자) 그래프가 그만큼 커집니다.

### 애니메이션

전환 애니메이션이 없습니다. 데이터가 바뀌면 바로 다시 그립니다.

## 사용 가이드라인 (Usage Guidelines)

### ✅ Do

<Callout type="tip">

**`label` · `valueLabel` 을 호출자 로케일로 포맷해서 넘기기**

```dart
CoreTrendPoint(date: date, value: 12480, label: '9월', valueLabel: '12,480명')
```

이유: 차트는 숫자 · 날짜를 포맷하지 않습니다. 생략하면 ISO 날짜와 그룹 구분 없는 숫자가 툴팁과 스크린 리더에 그대로 나옵니다.

</Callout>

---

### ❌ Don't

<Callout type="warning">

**막대 차트에 0 에서 먼 값만 넣어 변화를 키워 보이게 하기**

```dart
// ❌ 막대는 항상 0 에서 자라므로 9,980 과 10,020 의 차이가 거의 안 보인다
TrendChart(variant: CoreTrendChartVariant.bar, points: nearlyFlat)
```

이유: 막대의 길이는 값 자체를 뜻합니다. 작은 변동을 보여 주려면 축을 좁게 잡는 `line` 을 쓰세요.

</Callout>

## 접근성 (Accessibility)

### 역할

그래프 영역은 `semanticLabel` 을 이름으로 갖는 그룹입니다(Flutter `Semantics(container: true, label:)`, Web `role="group"` + `aria-label`). 그 안에 점마다 하나씩 「날짜, 값」 이름을 가진 항목이 있습니다(Flutter 점별 `Semantics(label:)`, Web `role="list"` 안의 `role="listitem"` + `aria-label`). 이 목록이 그래프의 데이터 표 대체 보기 역할을 합니다.

### 키보드

처리하는 키가 없습니다. 기간 칩은 `Chip` 의 키보드 동작을 따릅니다.

### 스크린 리더

그래프 이름을 읽은 뒤 점을 순서대로 「1월 1일, 3건」처럼 읽습니다. 값 축 · 날짜 축 라벨과 선 · 막대 · 격자는 장식이라 보조 기술에서 숨깁니다(Flutter `ExcludeSemantics`, Web `aria-hidden`). 기준선은 범례 문장으로 읽힙니다.

### 포커스 관리

그래프 자체는 포커스를 받지 않습니다. 점별 툴팁은 hover 로 열리므로 키보드로는 열 수 없지만, 같은 내용이 각 점의 접근 가능한 이름에 있습니다.

### 알려진 제약

- 시리즈는 하나입니다. 여러 시리즈를 비교하려면 차트를 나란히 둡니다.
- 점은 시간 간격과 무관하게 목록 순서대로 같은 간격에 놓입니다.

> 감속 모션 · 고대비 · 강제 색상 · 최소 터치 타겟처럼 전 컴포넌트에 공통으로 걸리는 축은 [전역 접근성 축](/accessibility)에서 다룹니다.
