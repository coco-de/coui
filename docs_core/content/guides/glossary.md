# 용어 풀이

문서를 읽다가 낯선 말이 나오면 여기서 찾습니다. 한 줄 뜻과, 더 자세히 다루는
페이지를 함께 적었습니다.

## 컴포넌트를 쓸 때 만나는 말

| 말 | 뜻 | 더 보기 |
|---|---|---|
| **컴포넌트** | 화면을 이루는 부품 하나(`Button` · `Card`). Flutter 에서는 위젯, Jaspr Web 에서는 컴포넌트라고 부르지만 CoUI 에서는 이름과 쓰는 법이 같습니다. | [컴포넌트](/components-overview) |
| **슬롯** | 값이나 위젯을 끼워 넣는 자리. `leading:` · `title:` 처럼 위젯을 받는 자리는 **위젯 슬롯**, `cardStyle:` 처럼 스타일 값을 받는 자리는 **스타일 슬롯**이라고 부릅니다. | [설계 원칙](/principles) |
| **겉모습** | 색 · 여백 · 테두리 · 모서리 · 그림자 · 글자 모양처럼 "어떻게 보이는지"를 정하는 값. 전부 스타일 슬롯(`xxxStyle`)으로 넣습니다. | [설계 원칙](/principles) |
| **스타일** (`CoreXxxStyle`) | 한 컴포넌트의 겉모습 값을 묶은 것. 필드는 전부 비워 둘 수 있고, 채운 필드만 기본값을 바꿉니다. | [테마](/guides/theming) |
| **안쪽 부품의 스타일** | 컴포넌트 안에 들어 있는 다른 컴포넌트에 넘기는 스타일. `Alert` 의 `closeButtonStyle` 은 그 안에 있는 닫기 `Button` 의 스타일입니다. | 각 컴포넌트의 스타일 표 |
| **variant** (변형) | 같은 컴포넌트의 종류를 고르는 값. `Button` 의 `primary` · `outline` · `ghost` 처럼, 미리 정해 둔 겉모습 한 벌을 고릅니다. | 각 컴포넌트의 "변형" |
| **테마** (`CoreComponentTheme`) | 앱 전체에 한 번 정하는 기본 스타일. 여기서 바꾼 값은 그 컴포넌트를 쓰는 모든 곳에 적용됩니다. | [테마](/guides/theming) |
| **값이 정해지는 순서** | 같은 값을 여러 곳에서 줄 수 있을 때 무엇이 이기는지. 디자인 시스템 기본값 → 테마 → variant 별 테마 → 그 위젯에 직접 준 스타일 순서이고, 뒤로 갈수록 이깁니다. | [테마](/guides/theming) |
| **오버라이드** | 기본값을 다른 값으로 덮어쓰는 것. | [테마](/guides/theming) |
| **chain** (체인) | `Text('제목').titleLarge.semiBold` 처럼 점으로 이어 붙여 스타일을 얹는 쓰기 방식. | [타이포그래피](/guides/typography) |
| **호출자** | 그 컴포넌트를 가져다 쓰는 쪽의 코드. "호출자가 넘긴 `attributes`" 는 여러분의 코드가 넘긴 값입니다. | — |

## 디자인 값에 관한 말

| 말 | 뜻 | 더 보기 |
|---|---|---|
| **토큰** | 이름이 붙은 디자인 값. 숫자나 색을 직접 쓰는 대신 `CoreSpace.space16` · `CoreColors.primary` 같은 이름을 씁니다. | [디자인 토큰](/tokens/overview) |
| **프리미티브** | 값 그 자체에 붙인 이름. 파란색 램프의 한 단계, 16px 간격이 여기에 듭니다. | [색상](/guides/colors) |
| **시맨틱 색 · 시맨틱 토큰** | 쓰임새에 붙인 이름(`primary` · `onSurface`). 화면에는 이 이름을 쓰고, 다크 모드와 테마가 그 뒤의 값을 바꿉니다. | [색상](/guides/colors) |
| **alias** | 토큰에 붙인 또 하나의 이름. `CoreDuration.fast` 는 150ms 를 "빠른 전환"이라는 쓰임새로 부르는 이름입니다. | [모션](/guides/animation) |
| **서페이스 스타일** | 유리 · 점토 같은 재질의 느낌을 앱 전체에 한 번에 입히는 설정. | [서페이스 스타일](/guides/surface-styles) |

## 화면과 접근성에 관한 말

| 말 | 뜻 |
|---|---|
| **포커스 링** | 키보드로 이동할 때, 지금 선택된 요소 둘레에 그려지는 테두리. |
| **탭 정지점** (tab stop) | Tab 키를 눌렀을 때 멈추는 자리. 탭 막대나 메뉴처럼 한 묶음이 탭 정지점을 하나만 갖고 그 안은 화살표로 옮기는 방식을 roving tabindex 라고 부릅니다. |
| **live region** | 화면의 내용이 바뀌었을 때 스크린 리더가 그 내용을 읽어 주는 영역. |
| **스크림** (scrim) | 대화상자나 서랍 뒤를 어둡게 가리는 막. |
| **폴백** (fallback) | 값이 없을 때 대신 쓰는 값. |
| **래퍼** (wrapper) | 다른 것을 감싸는 요소나 위젯. |
| **네이티브** | 브라우저나 운영체제가 원래 제공하는 것. "네이티브 `<input>`" 은 브라우저의 입력 요소입니다. |
| **hydrate** | 서버가 미리 그려 보낸 HTML 에 브라우저에서 스크립트가 붙어 동작하기 시작하는 것. 이 문서는 "깨어난다"고도 씁니다. |

## 이 문서가 쓰지 않는 말

아래는 킷을 만드는 쪽에서 쓰는 말입니다. 문서 본문에서는 오른쪽 말로 풀어 씁니다.
소스 코드의 주석이나 이전 버전 문서에서 왼쪽 말을 만나면 이 표로 읽으면 됩니다.

| 만드는 쪽의 말 | 이 문서에서는 |
|---|---|
| `chrome` · `크롬` | 겉모습 |
| `dimensional` | 크기 · 간격 |
| `nested slot` | 안쪽 부품의 스타일 |
| `단일 진입점` · `단일 슬롯` | `xxxStyle` 하나 |
| `resolve chain` | 값이 정해지는 순서 |
| `resolver` | 스타일을 계산하는 내부 코드 — 본문에서는 따로 부르지 않습니다 |
| `emit` | 내보낸다 · 붙인다 |
| `passthrough` | 그대로 넘긴다 |
| `paint-ready` | 바로 그릴 수 있는 값 |
| `raw-forward` | 그대로 넘긴다 |
| `flat` 파라미터 · `평면` 필드 | 낱개 파라미터 · 낱개 필드 |
| `behaviour` | 동작 |
| `시맨틱 enum` | 종류를 고르는 값 (`variant` · `size`) |
| `합성 슬롯` | 위젯 슬롯 |
| `중첩 슬롯` | 안쪽 부품의 스타일 |
| `단일 출처` | "한 곳에서 정한다" |
| `ambient` | 주변의 · 위에서 내려 준 |
| `caller` | 호출자 |
| `capability` | 기능 |
| `intrinsic` 크기 | 내용 크기 |

> 컴포넌트 페이지의 **스타일 필드 표**는 소스 코드에서 각 필드 주석의 첫 문단으로
> 자동으로 만들어집니다. 그 설명은 영어이고, 위 표의 말 대신 풀어 쓴 말을 씁니다
> (`caller` · `behavior` 처럼 영어에서 흔한 말은 그대로 둡니다).
